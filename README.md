# 株式会社豊栄製作所 コーポレートサイト

株式会社豊栄製作所の公式ホームページのソースコードです。

## ディレクトリ構成

```
.
├── src/                 # サイトのソース
│   ├── index.html
│   └── assets/
│       ├── css/
│       ├── js/
│       └── images/
├── docs/                # 企画・仕様などのドキュメント
└── README.md
```

## 開発

```bash
# ローカルで確認（例）
open src/index.html
```

## ブランチ運用

- `main`: 公開用（常にデプロイ可能な状態を保つ）
- `feature/*`: 機能・ページ追加
- `fix/*`: 修正

## コミットメッセージ

`feat:` / `fix:` / `docs:` / `style:` / `chore:` の接頭辞を付けてください。
